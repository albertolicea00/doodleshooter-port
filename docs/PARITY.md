Work order: rebuild and validate Android, compare solo movement/combat and presentation against the reference, verify native client/server matches and rules, resume iOS and verify both platforms, then add maps. LAN hosting runs inside the game; online is experimental and requires a separately running server. Interoperability with web lobbies is not implemented. The original's online uses PeerJS public signalling and direct WebRTC with STUN only (no TURN); a native PeerJS/WebRTC mode (port-only first, then cross-play with the original's maps and weapons) is planned but waits on bundling the Godot WebRTC extension. When implemented it will share the original's limitation: players both behind strict NAT may be unable to connect.

The port-only lobby includes a setup subtitle (with waiting guidance for guests). Map selection retains its original port card styling with rounded upper preview corners; this presentation is not part of the original game.

Play offline reuses the LAN host's full-width animated map strip below the subtitle and above the Survival/Bot match setup cards. The selected map applies to either offline mode; this inline picker is port UI, not part of the original game.

The port-only animated map cards use 120 views per orbit at 30 frames per second (four seconds per turn), replacing the original port's ten-view reel. Preview images are stored as 12×10 atlases with 160-pixel cells; this is presentation added by the port, not original game behavior.

Offline map selection updates the existing cards in place, with an exclusive selected highlight. All preview cards share an uptime-based rotation phase, so rebuilding a lobby does not restart their orbit. This remains port-only menu presentation.

LAN host lobby refreshes retain the existing map row, preview textures, and running timer across server acknowledgments and setup/roster updates. The authoritative map selection is applied to the retained cards; leaving the lobby frees the row normally.

Play online keeps a compact two-button map selector to the right of the server URL: **Doodle District** (`default global map`) beside a reusable custom-map button (**Select custom map**, `choose from 9 maps`, or the chosen map name with `custom map · tap to change`) that opens the animated nine-map picker for all non-District maps (choosing maps beyond District/Jungle is a port addition). Its selection is independent of offline/LAN maps and feeds quick play and private/public room creation. Offline and LAN keep the animated ten-map strip.

Port-only menu presentation additions: the main menu shows `DOODLE SHOOTER` with lowercase red `port`, subtitle `native port, portable too`, the version label under the subtitle, a tilted `START` button, `PLAY ONLINE` / `PLAY LAN`, stacked `CONTROLS` / `SETTINGS` / `CREDITS`, and `EXIT`. Play Offline adds a red-outlined `CHECKPOINT · WAVE <N>` button next to the Survival heading when `checkpoint >= 5`. All menus share tilted headings with tight subtitle spacing, non-selectable `RichTextLabel` text, `PS CONTROLLER` in Controls, a top-center navigation hint (`A / ✕ Select · Arrows / D-pad Move & Scroll · B / ○ Back` using the inline SVG Cross/Circle icons, hidden on scroll), debounced/rate-limited menu directional and confirm/back inputs, black focus outlines with a focus blip and continuous pulse, `ui_cancel` back navigation, `LineEdit` initial-focus skipping, and autoscroll on license/full-credits screens. A lightweight menu background replay (`DoodleReplay`) records the last 30 seconds of gameplay at 15 Hz to `user://last_replay.json` and falls back to a default District panoramic loop when no saved replay exists.
